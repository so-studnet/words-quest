# 要件（Words Quest）

英語の単語・熟語・イディオム・文章を入力すると、辞書的な説明・類義語・対義語・例文を英語で返す Web サイト。将来は Web API として外部（自分の別サイト）からも検索できるようにする。

## 前提

| 項目 | 内容 |
|---|---|
| 利用者 | 自分だけ（＋自分の別サイトから API で利用） |
| 端末 | スマホ優先。PC でも使える |
| ログイン | 検索・API はログインなしで使える。学習記録と復習だけ、自分1人がログインして使う |
| 費用 | 完全に無料の範囲（クレジットカードを登録しない） |
| サイトの言語 | 画面・結果・エラーメッセージはすべて英語。開発用ドキュメントは日本語 |
| 開発者の PC | Windows（PowerShell） |
| 名前・URL | Words Quest / `words-quest.vercel.app` 形式（Vercel の無料ドメイン） |

## 機能要件

### F1 検索
- 入力欄に1つの語・熟語・イディオム・文章を入れて検索する
- 入力は前後の空白を除き、連続する空白は1つにまとめる。全角英数字・曲がった引用符などは半角に直す
- 受け付けるのは英字・数字・基本的な記号（`. , ! ? ; : ' " ( ) - / &`）だけ。英字を含まない入力・日本語を含む入力・300 文字を超える入力はエラーを英語で表示する
- 入力の種類を自動で判定する（F2）

### F2 入力の種類の判定
- **word**：単語が1つ（`well-being`・`don't` も1語）。前後の記号は取り除く（`Hello!` → `Hello`）
- **phrase**：2〜5語（熟語・句動詞・イディオム）
- **sentence**：6語以上、または3語以上で `. ! ?` で終わるもの
- 判定の境界は `src/lib/domain/query.ts` とそのテストで固定する

### F3 結果の表示
すべて生成 AI に問い合わせて作る（辞書 API は使わない）。
- **word**：発音記号、品詞ごとの定義、各定義の例文、類義語、対義語
- **phrase**：意味（言い換え）、定義、例文、類義表現、反対の意味の表現
- **sentence**：やさしい英語での言い換え、文法・語調・ポイントになる表現の説明、似た意味の言い回し
- 類義語・対義語は押すとその語で検索する
- 検索した語は URL（`/?q=...`）に入るので、ブラウザの「戻る」で前の結果に戻れ、URL を共有・ブックマークできる
- 「見つからない」にするのは、意味のない文字列や英語でない入力だけ。普通の英単語の組み合わせは、決まった表現でなくても文字どおりの意味を説明し、そのことを Notes に書く。打ち間違いらしければ、意図していそうな表現も Notes に書く（例：`the world stem` → `word stem`）
- 発音はブラウザの読み上げ機能（Web Speech API、英語 en-US）で聞ける（無料）。見出しと各例文にスピーカーのボタンを付ける。使えないブラウザではボタンを出さない
- 通信エラー・AI の不調のときは「Try again」で再試行できる（見つからないときは出さない）

### F4 検索履歴
- 最近検索した語をブラウザ内（localStorage）に保存し、一覧から再検索できる
- 検索が成功したものだけを残す（見つからなかった語・エラーは残さない）
- 最大 50 件。同じ語（大文字・小文字の違いは無視）は先頭に移す
- 1件ずつ「×」で消せる。「Clear all」は2回押しで全件削除
- 履歴がないときは、試せる例（serendipity など）を表示する
- 保存データが壊れていたら、壊れた項目だけ捨てる
- 将来：お気に入り・単語帳（F7 の復習通知につなげる）

### F5 結果のキャッシュ
- 一度調べた結果をサーバー側（Supabase）に保存し、同じ入力（小文字化したキー）の2回目からは AI に問い合わせない
- 目的：速さと、AI の無料枠の節約
- 保存するのは成功した結果だけ（見つからない・エラーは保存しない）
- 保存結果に期限は付けない。プロンプトや結果の形を変えたときは版を上げて作り直す
- Supabase が止まっていても検索は動く（AI に直接問い合わせる）

### F6 公開 API（簡易）
- `GET /api/v1/lookup?q=<入力>` が JSON（`LookupResult`）を返す。サイトの画面も同じ API を使う
- API キーは使わない
- ブラウザから呼べるのは、このサイト自身と `ALLOWED_ORIGINS`（環境変数・カンマ区切り）に書いたサイトだけ。それ以外のサイトのブラウザからは 403 `forbidden_origin`。`*` で誰でも許可
- サーバーからの呼び出し（Origin ヘッダーなし。curl など）はどこからでも受ける（回数制限はかかる）
- 使い方の説明ページ `/docs/api`（英語）。トップの下に「API」のリンク
- 使いすぎ防止：AI に問い合わせる回数だけを数える（保存済みの結果は無制限）。IP ごとに1時間 30 回、サイト全体で1日（UTC）500 回。環境変数で変えられる
- エラーは `{ "error": { "code": "...", "message": "..." } }` の形で返す

### F7 PWA・通知（M6）
- ホーム画面に追加できる（PWA：マニフェスト・アイコン・Service Worker。オフライン用のキャッシュはしない）
- 「今日の単語（Word of the Day）」：アプリ内の 184 語の一覧から日付で1語を選ぶ。同じ日はどの端末でも同じ語で、184 日間は同じ語が出ない
- トップ画面（検索していないとき）に今日の単語のカードを出す。押すと検索する
- ログイン中に Learned の「Word of the Day」で、この端末の通知をオンにする。時刻は 0〜23 時から選べる（既定は午前 8 時、端末のタイムゾーン）
- 通知は1日1回。本文は今日の単語の1つ目の定義（AI に聞いた結果は保存するので、1日1回まで）。押すとその語の検索を開く
- 指定の時刻から3時間以内に送る（毎時の呼び出しが1回抜けても届くように。夜にオンにしても、その日の朝の分がいきなり届かないように）
- ログアウトすると、その端末の通知は止まる。届かなくなった端末（410 など）は自動で消す
- iPhone はホーム画面に追加したアプリからだけ通知できる（iOS 16.4 以上）。Safari で開いているときは追加の案内を出す
- 通知用の鍵は、サイトの `/tools/keys` でブラウザの中で作る（どこにも送らない）

### F8 ログイン（自分だけ）
- メールアドレスとパスワードでログイン（`/login`）。新規登録はできない。アカウントは Supabase の画面で1つだけ作る
- ログインしていないときは、これまでどおり検索・履歴・API が使える（学習記録と復習の画面は「Sign in」を案内する）
- ログイン中は画面の下にタブ（Search / Learned / Review）。Review には今日の復習の数を出す
- ログアウトは Learned の一番下とログイン画面から

### F9 学習記録
- ログイン中に検索して成功したものを、すべて自動で記録する（単語・熟語・文章すべて）
- 語ごとに1つの項目（小文字にしたキーで同じものとみなす）と、検索・復習した日時を残す。同じ語を別の日に調べると、その日にも記録される
- 項目には結果（定義・例文など）を一緒に保存し、復習のときに使う。同じ語を調べ直すと新しい結果に置き換える（復習の予定は変えない）
- Learned で1件ずつ削除できる（2回押しで確定）。削除すると、その語の記録もすべて消える
- 初回ログイン時に、このブラウザの検索履歴（F4）を一度だけ取り込む。調べた日に学んだものとして入れる。結果は持っていないので、復習で答えを出すときに取り直して保存する

### F10 日ごとの一覧と集計（Learned）
- 今日学んだ数（初めて記録した語）、今日復習した数、いま復習が必要な数、連続して学習した日数（今日まだなら昨日まで）
- 全体の数と習得済みの数
- 直近 30 日の「学んだ数」の棒グラフ。棒を押す（PC では重ねる）とその日の学んだ数・復習した数を表示
- 日付ごとの一覧（新しい日が上）。その日に調べた語を1回ずつ、初めて学んだ日には「New」、次の復習日または「Mastered」を表示。押すと検索する
- 日付の区切りは日本時間の午前 0 時

### F11 復習（忘却曲線）
- 今日が復習日の語（過ぎたものを含む）を、復習日の古い順に1枚ずつ出す
- 語を見て思い出す → 「Show answer」で保存した結果を表示 → 「Forgot」か「Remembered」
- 間隔：学んだ翌日 → 3日後 → 7日後 → 14日後 → 30日後 → 60日後。60 日後も覚えていたら習得済みにして出さない
- 「Forgot」なら翌日からやり直し（1日後）。遅れて復習したときは、復習した日から次の間隔を数える
- 全部終わったら「All done for today!」と次の復習日

### F12 Anki のカードにする
- ログイン中に Learned の「Send to Anki」（`/anki`）から使う
- 学習記録の一覧（学んだ日ごと）にチェックを付けて選ぶ。All / Today / None で一括選択。日付の見出しのチェックでその日の分をまとめて選ぶ
- カード：表＝検索した語句、裏＝検索結果の全部（発音記号、言い換え、品詞ごとの定義・例文・類義語・対義語、Notes、全体の類義・反対の表現）。表→裏の1方向だけ
- 裏を開くと Anki の読み上げ（`{{tts en_US:Front}}`）で英語の発音が流れる
- デッキは「Words Quest」1つ、ノートタイプも「Words Quest」（Front / Back）。タグは種類（`word` / `phrase` / `sentence`）と学んだ日（`learned-YYYY-MM-DD`、日本時間）
- 渡し方は2つ
  - **.apkg**：PC ではダウンロード、iPhone・Android では共有メニュー（AnkiMobile を選ぶ）。語句ごとに決まった ID（GUID）を付けるので、同じ語句を入れ直すとカードは増えずに更新される
  - **PC の Anki に直接追加（AnkiConnect）**：PC の画面だけに出す。初回に Anki が「このサイトを許可するか」を聞く。同じ表のカードがあれば裏とタグを更新する。Anki から返事がないときは、許可の確認は 60 秒、ほかは 15 秒で止めて案内を出す
- 結果を持っていない項目（履歴から取り込んだもの）は、その場で検索して結果を学習記録に保存してからカードにする。取れなかったものは飛ばして名前を表示する
- アプリ内の復習（Review）とは独立（どちらで復習してもよい）

## 非機能要件
- スマホで片手で使える大きさ（入力欄・ボタンは大きく）。ダークモード対応
- 結果の形（`LookupResult`）は画面と API で共通。変えるときは API の版を上げる
- AI の応答は必ず検証してから表示・保存する（形が違えば捨てて「エラー」とする）
- 秘密の値（AI の API キー、Supabase の Secret key）はサーバー側の環境変数だけに置き、ブラウザに出さない
- 無料枠を超えたときは有料に切り替わらず「今は使えない」と表示する

## 対象外
- 自分以外のアカウント（新規登録）
- 日本語での説明、日本語からの検索
- 有料のプラン・API キーの発行
- 他人への API の公開
