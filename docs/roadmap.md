## ユーザーの PC での確認（M2）
- `.env.example` をコピーして `.env.local` を作り、`GROQ_API_KEY=` に Groq のキーを入れる（キーは会話に貼らない）
- `npm run dev` で http://localhost:3000 を開いて検索する
